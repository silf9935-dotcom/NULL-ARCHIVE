# NULL ARCHIVE

A slow-burn psychological horror / ARG mod for **Minecraft 1.21.1**, **Minecraft Forge 52.x**, and **Java 21**.

> The archive is not corrupted. It is correcting itself.

## New direction

NULL ARCHIVE is moving away from a command-built horror facility toward an ordinary survival world that slowly becomes wrong. The first overworld anomaly layer is now implemented: after a short quiet period, rare ambient events can produce distant footsteps, impossible sounds, brief smoke/portal traces, and unsettling messages. Events become more varied as the player spends time in the world.

These first events are deliberately cosmetic: they do not destroy terrain, damage players, or grief builds.

## Development status

**Early playable prototype — not a finished release.** The new overworld event system is an initial foundation, not yet the complete experience. The older six-stage recorder investigation and command-built facility remain in the project while the design transitions.

Planned expansion includes unique entities with distinct behaviour, more random world events, strange naturally placed structures, corrupted visual/audio effects, configurable event intensity, and a coherent ARG-style progression. Custom entity models, polished audiovisual assets, and extensive in-game playtesting are not complete.

## Requirements

- Java 21 JDK
- Gradle 8.8 installed locally (the repository currently has no Gradle wrapper)
- Minecraft Forge 52.x for Minecraft 1.21.1

## Build

Run from the project root:

```bash
gradle build
```

The distributable JAR should be written to `build/libs/`. GitHub Actions compiles the mod with Java 21 and ForgeGradle and uploads the JAR from successful runs as a workflow artifact. Open the [Actions page](https://github.com/silf9935-dotcom/NULL-ARCHIVE/actions), select the latest successful Build run, and download its artifact.

## Current gameplay

- Start a normal survival world. No command is required for the new overworld anomaly layer.
- The first two minutes are quiet by design.
- After that, rare anomalies may occur. They are intentionally infrequent and become more varied over playtime.
- The old test facility can still be generated by an operator with `/nullarchive generate`; this is legacy prototype content, not the intended new-world start.
- `/nullarchive status`, `/nullarchive reset`, and `/archivejournal` remain available for the older investigation prototype.

**World safety:** current overworld anomalies are cosmetic and do not alter blocks. The legacy facility generator replaces blocks in its footprint and should only be used in a disposable test world.

## Project layout

- `src/main/java` — mod code
- `src/main/resources/META-INF/mods.toml` — Forge metadata
- `src/main/resources/assets/nullarchive` — language, models, sound definitions, and textures
- `docs/` — design, playtest, and implementation notes
