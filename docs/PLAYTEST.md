# NULL ARCHIVE — Prototype Playtest

This is an early mechanics prototype. It includes a command-built seven-room archive layout and a conditional ending interaction, but not automatic world generation, custom textures, or a journal GUI.

## Quick test (creative mode)

1. Enter a world and open the NULL ARCHIVE creative tab. Use `/archivejournal` at any time to view tape progress, the eight distinct clue slots, ending requirements, Sealed Door unlock state, Rift scan state, Room 0 discovery state, and a phase-specific next-step hint (or a completion message after the ending).
2. Take the Field Recorder. Right-click to play tapes in order. Each successful playback confirms the recording and announces the next available phase; from tape 3 onward, the archive pulse accompanies phase advancement.
3. At the Intake counter, right-click the concrete block at the counter's center (relative position +4, +1, +2 from the generated facility origin) after tape 1 to reveal a one-time visitor log. The entry changes after tape 3; if discovered earlier, return after tape 3 for the one-time reveal.
4. Right-click Evidence Tape, Damaged Photograph, Memory Fragment, and Sealed Document to catalogue each item type once. Duplicates do not increase progress; the first catalogue consumes one item.
5. Use the recorder again. Later tapes require evidence.
6. Right-click Observation Glass after tape 2 to record a clue. Right-click Memory Block after tape 2 to inspect the terminal; the query is locked without a cartridge. After tape 3, a first empty-hand interaction also reveals a one-time memory echo. With at least two indexed clues, use a Terminal Cartridge on Memory Block to query `/SUBJECT/NULL/EXIT_LOG.txt` and record the terminal clue; the cartridge is consumed outside creative only for the first successful query. Repeated queries do not consume duplicates.
7. After tape 4 and three clues, use Archive Key on Sealed Door for the first unlock (consumed outside creative), then right-click to open/close it physically. The first unlock plays an archive pulse. Denied access before tape 4, without three clues, or without the key now has distinct sound feedback. The first access also catalogues the seal clue.
8. In the Records room (room 5), after tape 4 and at least two indexed clues, right-click the floor tile at the hidden shelf position to discover a one-time hidden record (clue 8).
9. Right-click Static Block, Null Block, or Corrupted Stone after the second tape to trigger escalating anomaly messages. Interactions have a 2-second cooldown to prevent spam; the escalation is player-wide. Right-click Archive Tile or Archive Concrete once per tape phase to discover phase-specific inscriptions; each phase's inscription is shown only once per player.
10. Track Archive Instability in `/archivejournal` and `/nullarchive status`: successful tape playback adds 5, each unique clue adds 8, the first Sealed Door unlock adds 10, EMF scans add 3, and the first Rift scan adds 15. Thresholds at 25/50/75 report pressure. At 100, one of four BREACH events fires (False Room, Recording Error, Shadow Trace, Memory Collapse), displays portal/smoke particles, and resets pressure to 35; breaches cannot repeat the same event consecutively and have a 60-second cooldown. The first breach at phase 4+ creates Room 0 past the Rift Chamber's east wall (coordinates +77..+85, z 0..8), opens a two-block-high tunnel through the Rift Chamber east wall and the Room 0 west wall, and adds a Null Block record at +81,+1,+4. Interact with that block after pressure has settled to at least 35 for a one-time secret message; it is not part of the eight standard clues. Reset removes Room 0 and restores the doorway wall. `/nullarchive reset` clears the instability, breach count, and event history while retaining the generated facility coordinates so the same layout remains playable. When run in the facility's dimension, it restores Room 0, the final-tape Rift changes, and the tracked Basement, Observation, Incident Lab, Sealed Wing, and Rift ambient mutations to their generated block states. It does not attempt to undo arbitrary player edits or unrelated world changes.
11. Hold the Null Shard and right-click facility anomaly blocks to index four optional resonances: Corrupted Stone (phase 2), Static Block (phase 3), Black Glass (phase 4), and Null Block (phase 4). Each type can be indexed once per investigation, adds 4 instability, and is not a standard evidence clue. The shard is not consumed; repeats give feedback without increasing pressure. Room 0’s centerpiece and the completed ending seal keep their dedicated interactions.
12. Use the EMF Reader while exploring: it scans phase-unlocked facility signals within roughly eight blocks, including nearby mutated anomaly blocks even when no authored landmark is in range. It reports strength from 1/5 to 5/5 and rough direction (ahead/behind, left/right, above/below). After the first breach opens Room 0, its central Null Block receives a distinct `ROOM 0` reading instead of the generic Null signal; `/archivejournal` also reports whether Record 000 is still undiscovered or has been copied. EMF scans do not catalogue clues. Also right-click the Null Shard, Archive Key, Rift Key, and Terminal Cartridge for their prototype responses; the keys and cartridge now respond according to whether their lock/query/ending state is already resolved. The Null Shard has phase-specific responses and a 1-second cooldown.
13. After generating the facility, proximity events trigger in Observation, Basement, Incident Lab, Sealed Wing, and Rift Chamber as you advance phases. Each event is once per generated layout. From phase 3 onward, the Observer may appear as a brief smoke/portal silhouette: beside the Records terminal in phases 3–4, behind you in phase 5, and inside the Rift Frame in phase 6. It is a particle-and-sound encounter, not a custom mob; each phase can trigger once, with a shared 45-second cooldown. After appearing, it performs a three-beat stalking sequence over roughly 3.5 seconds: a false chime from the side with a brief portal echo, a close distortion pulse, then silence. During the sequence, approaching within three blocks or looking directly at the saved silhouette (within twelve blocks) makes it vanish early, with smoke/portal particles and a distortion sound; this reaction starts a 15-second cooldown. `/nullarchive status` reports the encounter count. Reset clears Observer phase flags, encounter count, sequence stage/position, and cooldown.
14. At phase 5 or later, right-click the Rift Frame once for a one-time resonance scan; it adds narrative feedback but does not count as evidence. For the ending: play all six tapes, catalogue at least five distinct clues out of eight, then right-click the Rift Frame while holding the Rift Key. At 80% instability or higher, the ending changes to `ARCHIVE ERROR: SUBJECT OUTSIDE RECORD` and seals the frame with a Null Block instead of Black Glass. In creative mode the key is not consumed.

## Admin test commands

- `/nullarchive generate` — builds a compact seven-room facility around the player (permission level 2), then places you inside Intake facing the corridor. Run in an open area; it replaces blocks in its footprint and drops curated progression items. Rooms now have landmarks: Intake counter, Basement ceiling strips, Observation glass divider, Incident Lab anomaly floor, Records shelves, Sealed Wing warning floor, and Rift Chamber corrupted cross. It is a command-built prototype, not automatic world generation. Start in Intake and follow the corridor. The two-block sealed threshold is in the connector before Rift Chamber; first access requires tape 4, three clues, and the Archive Key.
- `/archivejournal` — player-accessible field journal: recording progress, distinct clue checklist, and ending requirements.
- `/nullarchive status` — shows tape phase, evidence count, anomaly count, Sealed Door unlock state, Rift scan state, and ending state (permission level 2).
- `/nullarchive reset` — resets player progression, phase inscriptions, clue interactions, anomaly/stalking triggers, Observer phase flags/count/active sequence, and their cooldowns while retaining the facility's saved location for replay. If run in the generated facility's dimension, it closes the two-block Sealed Door. When run in the facility's dimension, it restores Room 0, the known final-tape Rift wall/floor changes, and tracked ambient mutations (Basement floor patch, Observation wall, Incident Lab floor, Sealed Wing false passage, and Rift Null Block) to their generated baseline. Arbitrary player edits and unrelated world blocks are not reverted.
- `/nullarchive generate` also clears facility-specific interaction flags so a newly generated layout can be investigated again; catalogue progress remains with the player.

- The generator places Field Recorder, EMF Reader, evidence items, Terminal Cartridge, Archive Key, Rift Key, and Null Shard as item drops at room landmarks. Running the command again duplicates these drops. Ambient events are proximity-triggered, phase-gated, and each fires once per generation. From tape 3 onward, a phase-specific stalking cue can play a chime behind the player and report footsteps in the empty corridor; it fires once per phase while inside the facility. Observation changes a wall section to black glass; Basement and Incident Lab mutate floor patches into anomaly blocks; the Sealed Wing event turns a side-wall section into black glass with a Null Block embedded in it (a false passage); the Rift event adds a Null Block. These known mutations are restored by `/nullarchive reset` to their generated baseline. Playing tape 6 also rewrites the Rift Chamber: Null Blocks breach the wall and corrupted stone spreads across the floor; reset restores those known positions.

## Known limitations

- Progress and evidence are stored in player persistent data; there is no reset/journal UI yet.
- Evidence is now tracked by distinct item/clue flags: four evidence item types plus Observation Glass, Memory Block, Sealed Door, and the hidden Records room clues. The Rift ending still requires five distinct clues; duplicates cannot be farmed.
- Sealed Door now has a persistent open/closed state and changes collision so the player can pass; the open state uses an iron-bars visual placeholder.
- The EMF Reader is a proximity scanner prototype: it detects phase-gated landmarks within an 8-block radius and reports signal strength plus a rough direction along the facility corridor. It has a 1-second recalibration cooldown to limit scan spam. It is not precise navigation and does not add evidence.
- Null Shard resonance is a separate optional four-type index, not evidence; each first resonance adds 4 instability, while repeats do not. It can still trigger a breach if the pressure threshold is crossed.
- Most other interactions remain text-and-sound prototypes. `/nullarchive reset` restores only the documented generated positions for tracked ambient and ending mutations; it is not a general world rollback. The Rift Key ending physically seals the clicked frame with Black Glass or Null Block depending on instability, leaves the alternate block above, and changes the floor below to Corrupted Stone. Interacting with that seal after the ending returns a short confirmation response. This is a static seal, not an animation.
- Playing tape 6 triggers the final room-shift mutation once per playback (repeated playback is phase-locked). The sound registry currently uses vanilla sound assets.
- CI build must pass for the latest commit before calling this prototype verified.
